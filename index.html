Project Overview

This project is designed for MuleSoft training students to implement a basic Canteen Ordering System using API-led connectivity principles.

Goal

Build reusable MuleSoft APIs with CRUD operations and integrations.

Technology

MuleSoft Community Edition, RAML, DataWeave, MySQL/H2.

Deployment

Local Runtime Deployment only. No CloudHub required.
